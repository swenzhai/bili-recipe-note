## 2026-10-06：S 形虾仁蒸饺选图修复

素材为[小高姐《S形虾仁蒸饺》](https://www.bilibili.com/video/BV1yJ41137CY)，295.917 秒、1920×1080、24 fps，PTS time base 为 `1/16000`。此前两次默认预算任务均未找到匹配图片。

本次将选图策略升级为版本 `3`，修改主工程和 `external/video-frame-choose` 子模块：

- 粗筛按照实际解码的首末时间戳均匀分配预算，保留首末帧，避免旧压缩算法在成品片段留下过大空档。粗筛没有匹配且语义评分不能区分候选时，精筛探索尚未覆盖的时间空档；有有效线索时仍在候选附近精筛。
